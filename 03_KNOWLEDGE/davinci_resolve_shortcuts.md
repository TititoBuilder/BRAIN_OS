# DaVinci Resolve — Keyboard Shortcuts

Editing-page keyboard reference. Captured from a scratch note dropped in
`09_TOOLS/` under a garbage filename (the first line of pasted content);
deduplicated here — the source had the same shortcuts pasted three times.

## Playback & Transport
| Key | Action |
|---|---|
| Spacebar | Play / Pause |
| J / K / L | Reverse / Stop / Forward (shuttle) |

## In/Out & Trim
| Key | Action |
|---|---|
| I | Mark In |
| O | Mark Out |
| B | Blade tool (cut at playhead) |
| Ctrl+B | Cut at playhead without switching to blade tool |
| Delete | Remove selected clip (leaves gap) |
| Shift+Delete | Ripple delete (remove selected + close gap) |
| , / . | Nudge clip left / right by one frame |
| + / - | Zoom timeline |

## Navigation
| Key | Action |
|---|---|
| Left / Right | Previous / next frame |
| Up / Down | Previous / next edit point (cut) |
| Shift+Left/Right | Jump 1 second backward / forward |
| Home / End | Go to start / end of timeline |

## Markers
| Key | Action |
|---|---|
| M | Add marker at playhead (default color) |
| Shift+M | Add marker with dialog (choose color + note) |
| Ctrl+Arrow | Jump between markers |

## Other
| Key | Action |
|---|---|
| N | Toggle snap on/off |
| Ctrl+Z | Undo |
| Ctrl+S | Save project |
| F9 | Append clip to timeline (from viewer) |
